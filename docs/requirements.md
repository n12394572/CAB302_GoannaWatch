# Project Requirements
Finalised 12/08/2026

1. Log observations (dates,locations etc.)
2. Label records by species or habitat
3. Visualise previous data
   - Map of previously recorded animals
   - Charts of recorded animal quantities
4. Generate environmental monitoring reports
   - Weather, humidity, wind trends
5. Database: tables for users + records
6. UI: tabs for map, profile, additional information, reports

## Scope notes (team discussion 12/08)
- Observation logging starts with descriptor input only.
- Photo/video upload planned for a later iteration.
- ML-assisted species identification may follow after that.
